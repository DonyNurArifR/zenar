# Security policy

## Supported versions

Zenar is pre-1.0. Security fixes go into the latest release only.

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: go to the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it, and the version you tested.

This project is maintained by one person, so responses are best effort. You will get an acknowledgement, and a fix or an explanation of why there is none.

## Scope

Reports about the storage format, crash recovery, tenant isolation in filtered search, and the Python bindings are all in scope. Problems in third-party dependencies (TurboVec, PyO3) should also be reported to their own projects.
